# Huay968 — วิธีติดตั้งบนมือถือ

1. สร้าง repository ใหม่บน GitHub ชื่อ `huay968` (ตั้งเป็น Public)
2. กด "Add file" → "Upload files" แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (ไม่ต้องใส่โฟลเดอร์ซ้อน)
3. ไปที่ Settings → Pages → Source เลือก "Deploy from a branch" → Branch `main` / `(root)` → Save
4. รอ 1–2 นาที แอปจะอยู่ที่ `https://<ชื่อผู้ใช้ GitHub>.github.io/huay968/`
5. เปิดลิงก์นั้นใน Chrome บนมือถือ แล้วกดปุ่ม "⬇ ติดตั้งแอป" ที่แถบบน
   (ถ้าไม่เห็นปุ่ม ให้กด ⋮ → "ติดตั้งแอป" หรือ "เพิ่มลงในหน้าจอหลัก")

## การอ่านภาพหน้าจอ (ไม่บังคับ)
แท็บ "เพิ่มผล" → "ตั้งค่าการอ่านภาพ" → วาง Claude API key จาก console.anthropic.com
key เก็บในเครื่องนี้เท่านั้น ถ้าไม่ใส่ key ก็กรอกตัวเลขเองได้

## ข้อมูล
งวดที่เพิ่มเก็บในเครื่องนี้ ใช้ปุ่ม "สำรองข้อมูล" ในแท็บย้อนหลังเป็นระยะ
